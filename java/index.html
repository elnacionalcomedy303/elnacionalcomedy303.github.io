[01] Trayectoria y Filosofía en Java

Java fue mi primer lenguaje de programación real. Con él aprendí a estructurar la lógica de forma disciplinada, dominar el tipado fuerte y comprender en profundidad la Programación Orientada a Objetos (POO).

En el desarrollo de software valoro especialmente la robusteza y el control de errores. Me enfoco en la captura limpia de excepciones para evitar fallos inesperados, así como en la constante adición e iteración de nuevas funcionalidades que aporten valor a la aplicación.

[02] Proyecto Destacado: Plataforma Web de Red Social

Actualmente desarrollo una plataforma web integral estructurada como una red social. La arquitectura conecta una interfaz web interactiva con un motor Back-End capaz de procesar operaciones complejas y gestionar la persistencia de datos relacionales.

En este proyecto combino tecnologías de servidor y persistencia como Spring Boot, JDBC y MySQL (Workbench), comunicándose con la capa cliente mediante intercambio asíncrono de datos con JSON y Fetch API en JavaScript.
