[01] Experiencia y Aprendizaje Progresivo

Mi contacto con JavaScript ha sido más puntual en comparación con lenguajes como Java. Acostumbrado a la rigidez y el tipado fuerte de Java, al principio JS me resulta un entorno algo peculiar y diferente de estructurar.

Sin embargo, estoy totalmente concienciado de su importancia y enfocado en dominarlo. Entiendo que es la pieza clave para que la capa cliente de mi proyecto personal (red social) sea dinámica, atractiva y verdaderamente funcional para el usuario.

[02] Aplicación en el Proyecto Personal y Prototipos

• Conexión con el Back-End (Fetch API): Utilizo JavaScript para consumir los servicios REST construidos en Java / Spring Boot, gestionando el intercambio de datos en formato JSON sin necesidad de recargar la página.

• Manipulación del DOM y Eventos: Implemento lógica para capturar acciones del usuario en tiempo real, manejar eventos de teclado e interactuar con elementos multimedia como la Web Audio API.

[03] Herramientas y Objetivos Clave

JavaScript ES6+ Consumo de APIs con Fetch Manejo Asíncrono (JSON) Manipulación Dinámica del DOM Captura de Eventos de Teclado Integración Cliente-Servidor
